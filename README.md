# Hiszpański Franka — pełna paczka

Prosta, responsywna aplikacja edukacyjna do ćwiczenia hiszpańskiego w przeglądarce.

## Co zawiera
- Unidad Inicial: podstawowe powitania i zwroty
- Otoño: jesień, przyroda, kolory i pogoda
- Invierno: zima, ubrania i pogoda
- Primavera: wiosna, ogród, zwierzęta i aktywności
- Verano: lato, plaża, owoce, ubrania i zabawy
- Fiszki, syntezę mowy w przeglądarce, tryb ukrywania polskich podpowiedzi i quiz z punktami
- Jeden plik `index.html`, bez zewnętrznych bibliotek

## Uruchomienie lokalne
Rozpakuj ZIP i otwórz `index.html` w aktualnej przeglądarce. Odsłuch zależy od głosu hiszpańskiego dostępnego w urządzeniu.

## Publikacja w GitHub Pages
1. Utwórz repozytorium i dodaj `index.html` oraz ten plik `README.md`.
2. W repozytorium otwórz **Settings → Pages**.
3. W sekcji publikowania wybierz **Deploy from a branch**, gałąź `main` i folder `/(root)`, a następnie zapisz.
4. Po zakończeniu publikacji GitHub pokaże adres strony.

**Ważne:** standardowa strona GitHub Pages jest publicznie dostępna. Nie umieszczaj tam prywatnych danych. Jeśli aplikacja ma być wyłącznie dla rodziny, wybierz hosting z ochroną dostępu, np. Cloudflare Pages skonfigurowane z Cloudflare Access i listą dozwolonych adresów e-mail.

Jeżeli wcześniejsze konto GitHub nadal jest zawieszone, najpierw wyjaśnij sprawę z pomocą GitHub. Nie używaj nowego konta do obchodzenia zawieszenia.

## Materiały
Zestawy słówek i ćwiczeń w tej paczce są autorskim materiałem ćwiczeniowym opartym na ogólnych tematach nauki języka. Nie zawierają skanów, ilustracji ani długich przepisanych fragmentów podręcznika. Przed wykorzystaniem w szkole sprawdź słownictwo i wymowę z materiałami nauczyciela.
